# Deme PvP HUD (Minecraft 1.21.11)

A lightweight client-side HUD for Fabric. It displays FPS, player coordinates, left/right clicks per second (CPS), and movement keys.

## Build

This project is built automatically by GitHub Actions. Open the **Actions** tab and download the `deme-pvp-hud` artifact from a successful run.

## Install

1. Use Minecraft Java Edition **1.21.11** with **Fabric Loader** and **Fabric API 0.141.6+1.21.11**.
2. Download the compiled mod JAR from the Actions artifact.
3. Put the mod JAR in your Minecraft `mods` folder.
4. Launch the Fabric 1.21.11 profile.

This is a HUD-only utility. It does not include an auto-clicker or automated combat actions.
